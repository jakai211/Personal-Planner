# Personal Planner · Weekwise

An offline-first personal planner for desktop and iPhone, built with React, TypeScript, Bootstrap, and IndexedDB. One block calendar brings work, school, personal events, and task sessions together.

## Local preview

```sh
npm install
npm run dev
```

No cloud account is needed for the local planner. Optional cloud services and full usage documentation are being added in subsequent commits.

## Development checks

```sh
npm run build
npm test
```

This repository contains application source only. Never commit `.env.local`, service-role keys, private push keys, backups, or personal calendar/email data.
